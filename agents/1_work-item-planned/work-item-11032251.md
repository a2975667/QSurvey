Render Likert Questions for Respondents
ID: 11032251
Owner: Frontend
Status: Proposed
Last Updated: 2025-11-20

Problem Statement
- Respondent UI currently handles QV and Text only; Likert questions are not rendered for respondents.

Expected Behavior / Shape
- Survey JSON contains Likert questions with fields: `_id`, `type: "likert"`, `question`, `description?`, `scale` (array of string values), `minLabel?`, `maxLabel?`.
- Respondent view should render a dropdown (or radio row) built from `scale` values; min/max labels shown as helper text.
- Submission shape: `{ responses: [{ questionId, responseContent: { value: "<selected scale value>", type: "likert" } }] }` (matching existing response DTO expectations for likert).

Tasks
- In respondent survey page, detect `type === 'likert'` and render a selection control (dropdown recommended) listing the scale values in order. Show min/max labels if present.
- Validate selection before submit; disable submit if no selection.
- On submit, post the likert response in the shape above; ensure it coexists with QV/Text submissions.
- Preserve survey question order from `survey.questions`—do not reorder to put QV first.

Verification
- Manual: build a survey with Text → QV → Likert; as respondent, see questions in that order, select a Likert value, submit successfully.
- Automated: component test for Likert rendering with provided `scale` and submission payload containing `responseContent.value` and `type: "likert"`.
